Extract financials from PDF

Best-effort, in-browser extraction — it scans the PDF for statement headings and known line-item labels, then shows you exactly what it found so you can correct anything before it's saved. Nothing leaves your browser. Works on two side-by-side year columns per statement (the usual annual-report layout); re-run it against another filing to add more years.

GitHub sync

Reads/writes company JSON via the GitHub Contents API. Only works when this page is self-hosted (e.g. on GitHub Pages) — a published Claude artifact preview can't reach external APIs, so these calls will fail there by design.
